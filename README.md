# Raviranjan.OS — Personal Developer Platform

Production-grade developer operating system, live telemetry dashboard, and engineering portfolio for Raviranjan Kumar.

## Architecture
- **Backend**: Java 21, Spring Boot 3, Flyway Migrations, JWT Auth, HikariCP, Maven
- **Database**: Neon Cloud Serverless PostgreSQL
- **Frontend**: Single-page modern Linear/Stripe design system, Tailwind CSS, Lucide Icons, JetBrains Mono & Plus Jakarta Sans
- **Deployment**: Render Cloud (Spring Boot JAR) & Vercel Edge (Reverse Proxy & Frontend)
